voxy.refprep¶

Prepare a speaker’s recordings for cloning and fine-tuning: clean, cut, transcribe, score.

>>> from voxy import refprep
>>> clips = refprep.prepare_reference(["tape1.m4a", "tape2.mp3"], voice="ada")
>>> ref = refprep.best_references(clips)[0]
>>> ref["path"], ref["text"], ref["score"]

The steps, each a function you can call alone or replace:

  1. condition (ffmpeg): any format to mono PCM WAV at sample_rate, with a high-pass, optional denoising (denoise=: ‘afftdn’, ‘anlmdn’, ‘deepfilternet’, or None) and loudness normalisation (EBU R128, loudness_lufs).

  2. transcribe: timed segments and words from a local Whisper (scribed’s faster-whisper backend, in its own environment, see voxy.envs).

  3. speaker (optional, voxy.speakers.speaker_filter): marks words, and untranscribed stretches, spoken by someone other than the target voice.

  4. plan_clips: cut points at sentence/segment boundaries, so each clip is min_seconds-max_seconds long, carries its exact text, and never contains a marked word.

  5. score_clip: duration, signal-to-noise estimate, clipping, level, ASR confidence, speaking rate and (with a speaker step) the speaker match, folded into a score in [0, 1].

prepare_reference runs them all and saves the clips plus manifest.jsonl in the voice’s samples store (voxy.stores.samples_store), so any backend (a reference clip) and fine-tuning (voxy.finetune, the whole set) read the same data.

voxy.refprep.plan_clips(segments, *, min_seconds=3.0, max_seconds=12.0, pad_seconds=0.12, total_seconds=None)[source]¶

Clips [{start, end, text, words}] cut between words, ending sentences where possible.

Words accumulate until the clip passes min_seconds and a word ends a sentence (or the next word would push it past max_seconds). Cuts fall in the pause between two words, padded by up to pad_seconds. A word marked keep=False (someone else’s, see voxy.speakers) ends the clip before it, and the next clip starts after it.

>>> w = lambda s, e, t: {"start": s, "end": e, "text": t, "confidence": 0.9}
>>> segs = [{"words": [w(0, 1, "One"), w(1.1, 2, "two."), w(3, 4, "Three"),
...                    w(4.1, 5, "four.")], "start": 0, "end": 5, "text": ""}]
>>> [c["text"] for c in plan_clips(segs, min_seconds=1.5, max_seconds=3)]
['One two.', 'Three four.']
>>> segs[0]["words"].insert(2, {**w(2.2, 2.6, " yes"), "keep": False})
>>> [(c["text"], c["start"]) for c in plan_clips(segs, min_seconds=1.5, max_seconds=3)]
[('One two.', 0.0), ('Three four.', 2.88)]
Return type:

list[dict]

voxy.refprep.score_clip(samples, sample_rate, *, words=(), text='', min_seconds=3.0, max_seconds=12.0)[source]¶

Quality measures of a clip, and their combination score in [0, 1].

  • snr_db: loud-frame level minus quiet-frame level (speech vs floor).

  • clipped: fraction of samples at full scale.

  • level_db: level of the loud frames.

  • asr_confidence: mean Whisper word probability (low: mumbling, noise, music).

  • chars_per_second: speaking rate (outliers: bad alignment).

  • speaker_similarity: lowest match of a word to the target voice (words annotated by voxy.speakers; None otherwise).

>>> rng = np.random.default_rng(0)
>>> speechy = np.concatenate([0.3 * rng.standard_normal(40000), 0.001 * rng.standard_normal(8000)])
>>> s = score_clip(speechy, 8000, text="x" * 70)
>>> s["snr_db"] > 30, 0 < s["score"] <= 1
(True, True)
Return type:

dict

voxy.refprep.with_deepfilternet(conditioner=None, *, denoiser=None, rootdir=None)[source]¶

A conditioner that denoises with DeepFilterNet between two ffmpeg passes.

Pass 1 converts the source to a 48 kHz mono WAV (no filters); DeepFilterNet cleans it; pass 2 applies the usual filters (high-pass, loudness) and resamples to sample_rate. conditioner (default condition()) does both ffmpeg passes.

Return type:

Callable[..., Path]
