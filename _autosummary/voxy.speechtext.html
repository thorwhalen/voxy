voxy.speechtext

voxy.speechtext¶

Display text vs speech text, and spotting words a model may misread.

A text a person reads and the text a model should be given are not always the same. Measured case (French, a Qwen3-TTS clone): a verse line starting with a capitalised verb, “Est parti” after a line “Mon frere”, was read as the noun /est/ (“l’Est”) in 4 of 4 takes; lowercased (“est parti”) it was read correctly in 4 of 4. The capital, not the line break, is the trigger: line-initial “Est” tokenises like the noun in “l’Est”. ASR checks cannot catch this (Whisper hears “est” either way), so the fix is upstream:

  1. prepare_speech_text() turns display text into speech text: it lowercases a verse-initial capital that does not start a sentence (keeping deliberate capitals: words also capitalised mid-line, or named in keep), then applies a per-language respelling table and proper-name aliases, and returns every change it made.

  2. flag_risks() lists the words of a text a model may misread (heteronyms you supply, e.g. from Lexique; more detectors plug in through extra), saying which ones sit where the capital trigger bites. pos_detector() is one such detector: it tags the text and, for heteronyms whose part of speech picks the reading (French “est”: verb /ɛ/, noun /ɛst/), names the expected reading; llm_detector() asks a language model for the risky words and their readings.

Engines differ in what they accept: for several local models text is the only lever (they take no phonemes or SSML), so this is a text-level step; it plugs into LocalCloneSpeechModel(text_prep=...). Verifying the audio itself (phoneme recognition of the flagged words) is voxy.pronounce.

>>> text = "Mon frere\nEst parti\nLoin d'ici."
>>> prepare_speech_text(text).speech
"Mon frere\nest parti\nloin d'ici."
>>> prepare_speech_text(text, keep={"Est", "Loin"}).speech == text
True

A flag_risks() extra detector that asks a language model for risky words.

The model’s proposals are kept only when the word is really on the line it names, and an expected reading only when it is one of the proposed readings; a reply that is not a JSON list proposes nothing.

Parameters:

  • chat (Callable[[str], str] | None) – prompt -> reply text; default aix.chat (pip install 'voxy[aix]', keys and model from aix’s own config). Each call costs a model request.

  • language (str) – The text’s language, named in the prompt.

  • prompt (str) – A string.Template with $language and $text (numbered lines).

  • clitics (Collection[str]) – The clitics a word is elided onto in language (as pos_detector); a proposal for “l’Est” (or for “Est”, when the line only has it elided) carries the clitic, as flag_risks() gives it.

Display text in, speech text out, with a record of every change.

Parameters:

  • text (str) – The text as a reader sees it (lines may be verse lines).

  • lowercase_verse_initial (bool) – Lowercase a line-initial capital that does not start a sentence (the first line of a paragraph, or a line after one ending in . ! ? …, keeps its capital).

  • respellings (Mapping[str, str] | None) – Word -> same-sound spelling, whole words, case-insensitive (e.g. a language’s ambiguous forms written unambiguously).

  • aliases (Mapping[str, str] | None) – Proper name -> pronounceable spelling, whole words, case-insensitive.

  • transforms (Iterable[Callable[[str], str]]) – Extra text -> text steps applied last, over the whole text.
