voxy.separate

voxy.separate¶

Split a recording into the voice and the rest (music, noise) before using the voice.

A song or a noisy interview has to lose its backing before its voice can be cloned, transcribed or edited. separate runs Demucs (MIT; htdemucs_ft by default, the fine-tuned hybrid transformer) in its own environment, built on first use under the data root like the other local models, and returns the two stems as WAV bytes: the voice, and rest, the input minus the voice (so the two add back up to it).

>>> from voxy.separate import separate
>>> stems = separate("song.mp3")
>>> open("vocals.wav", "wb").write(stems["vocals"])

run is the seam ((audio_path, out_dir, *, stem, sample_rate, \*\*options) -> {stem: path}); tests and other separators plug in there.

>>> import tempfile, pathlib
>>> def fake(audio, out_dir, **options):
...     paths = {n: pathlib.Path(out_dir) / f"{n}.wav" for n in ("vocals", "rest")}
...     for p in paths.values():
...         p.write_bytes(b"RIFF")
...     return paths
>>> sorted(separate(b"RIFF....", run=fake))
['rest', 'vocals']

voxy.separate.separate(audio, *, stem='vocals', sample_rate=None, run=None, **options)[source]¶

{stem: wav, "rest": wav}: audio split into stem and everything else.

rest is the input minus the voice, so stem + rest rebuilds the input (as the model hears it: resampled and with its channels). Both are 16-bit PCM WAV with the model’s channels (Demucs: stereo; a mono input is duplicated, the first two channels of a wider one are kept) at the model’s rate (Demucs: 44.1 kHz) unless sample_rate says otherwise, whatever the input. If either stem would clip, both are divided by one common factor (Demucs’s prevent_clip), so they still add up to the input times that factor.

The whole file is decoded and held in memory, and Demucs takes about 24 s per minute of audio on CPU for one model (htdemucs_ft runs only the sub-model fine-tuned for stem); split hours-long recordings first.

Parameters:

  • audio (str | PathLike | bytes) – A path to any format soundfile reads (WAV, FLAC, OGG, MP3 with a recent libsndfile), or WAV bytes.

  • stem (str) – The stem to keep apart ("vocals"; Demucs also has drums, bass, other).

  • sample_rate (int | None) – The rate of the returned WAVs (default: the model’s).

  • run (Callable[..., Mapping[str, str]] | None) – (audio_path, out_dir, *, stem, sample_rate, \*\*options) -> {stem: path}; default worker_run() (Demucs htdemucs_ft on CPU).

  • **options – Passed to run (Demucs: shifts, overlap).

Return type:

dict[str, bytes]

voxy.separate.speech_separator(*, stem='vocals', run=None, **options)[source]¶

separate as a (samples (frames, channels), sample_rate) -> (speech, music) callable, the separator seam of reeleehq/mixing (mixing.audio.separation.separate_speech(audio, separator=speech_separator())), so mixing can run Demucs out of process, in voxy’s environment.

Mono or stereo in; the stems come back at the input’s rate, channels and length, at the input’s level (no clip rescaling, float WAV in between: speech + music is the input). Keyword arguments are separate’s. For mixing’s remove_talk, give it htdemucs’s context: SeparationStrategy(..., context_s=3.0) around this callable (a bare callable gets mixing’s 1 s default).

>>> def fake(audio, out_dir, *, stem, sample_rate, **options):
...     samples, sr = read_wav_channels(audio)
...     paths = {}
...     for name, part in ((stem, samples * 0.75), ("rest", samples * 0.25)):
...         paths[name] = f"{out_dir}/{name}.wav"
...         open(paths[name], "wb").write(write_wav_channels(part, sr))
...     return paths
>>> speech, music = speech_separator(run=fake)(np.ones((4, 2)), 8000)
>>> speech.shape, float(speech[0, 0]), float(music[0, 1])
((4, 2), 0.75, 0.25)
Return type:

Callable[[ndarray, int], tuple[ndarray, ndarray]]
