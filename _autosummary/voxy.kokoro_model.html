voxy.kokoro_model¶

Kokoro: a neutral local voice that needs no reference clip, no key and no GPU.

Kokoro-82M (weights Apache-2.0) through kokoro-onnx (MIT) speaks in 54 stock voices (af_heart, am_michael, bf_emma, …) and runs faster than realtime on a CPU. It runs in its own small environment, like the local cloners (voxy.local_clone): python -m voxy setup kokoro builds it, and the model files (about 354 MB) are fetched from the Hugging Face hub on first use into $VOXY_DATA_DIR/models/hf, like every other local backend’s weights.

>>> import voxy
>>> voxy.text_to_speech("Hello.", "bf_emma", backend="kokoro").save("hi.wav")

A voice’s first letter is its language (a American English, b British, f French, …) and its second its gender; lang follows the voice unless you pass one. The voice list is static (KOKORO_VOICES), so listing voices needs no model.

On macOS it works from a fresh environment (kokoro-onnx 0.6.1 with phonemizer 3.6 and espeakng-loader 0.2.4, checked on arm64; the older pins, thorwhalen/voxy#61, could not find espeak-ng’s data). If an environment built earlier still fails there, delete $VOXY_DATA_DIR/envs/kokoro and run python -m voxy setup kokoro.

>>> import numpy as np
>>> fake = lambda text, **kw: (np.full(800, 0.1, dtype=np.float32), 24000)
>>> speech = KokoroSpeechModel(generate=fake).synthesize("One. Two.", "bm_george")
>>> speech.backend, speech.voice, speech.sample_rate
('kokoro', 'bm_george', 24000)

Bases: LocalSpeechModel

Kokoro-82M as a voxy backend (params: speed; lang, else the voice’s).

Parameters:

  • voice (str | None) – Default stock voice (else $VOXY_KOKORO_VOICE, else ‘af_heart’).

  • voices (Iterable[str]) – The voices the model accepts (default KOKORO_VOICES). For a newer voices file, also pass init={'voices_file': ..., 'revision': ...}; names must start with a known language letter (KOKORO_LANGUAGES).

  • generate (Callable | None) – The model call (default: the worker, see LocalSpeechModel).

  • device (str) – Only ‘cpu’ (kokoro-onnx runs on onnxruntime’s CPU provider).

  • **kwargs – The other LocalSpeechModel options (threads, rootdir, …).
