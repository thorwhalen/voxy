voxy.pronounce

voxy.pronounce¶

Checking, in the audio, which reading of a flagged word a render used.

voxy.speechtext.flag_risks() lists the words a model may misread (heteronyms such as French “est” /ɛ/ vs “Est” /ɛst/). This module listens for the answer: it crops the word out of a render (word timestamps from ASR), asks a phoneme recogniser for its frame-wise phoneme log-probabilities, and scores each candidate reading by its CTC likelihood. The reading the audio supports best is the one the model said; a render whose word came out as the wrong one can be re-rendered.

The recogniser is facebook/wav2vec2-lv-60-espeak-cv-ft, run in its own torch env (PHONEME_ENV, built by voxy.envs). Its vocab.json maps espeak IPA symbols to ids, so candidate readings are written in IPA and tokenised against that vocabulary: no phonemizer is needed. Everything above the recogniser is pure numpy and takes the recogniser as an argument (emitter), so it is tested without torch.

>>> vocab = ["<pad>", "ɛ", "s", "t"]
>>> emissions = log_probs_from_path([1, 0, 0], vocab_size=4)  # hears /ɛ/ only
>>> best_reading(emissions, vocab, {"verb": "ɛ", "noun": "ɛst"})
'verb'

voxy.pronounce.checks_from_risks(risks, *, readings, expected=None)[source]¶

verify_words checks for the flagged words that have known IPA readings.

readings maps a word (case-insensitively) to {name: IPA}, e.g. from a Lexique-derived heteronym list the caller supplies; expected names the reading each word should have. Words with no entry are skipped. Each word is checked once: verify_words finds every place it is spoken.

Return type:

list[tuple[str, Mapping[str, str], str | None]]

voxy.pronounce.ctc_log_likelihood(log_probs, target, *, blank=0)[source]¶

log P(target | log_probs) under CTC (the forward algorithm, in log space).

log_probs is frames x vocab (log-softmax). -inf when the target cannot be aligned (more symbols than frames allow).

>>> lp = log_probs_from_path([1, 2], vocab_size=3)
>>> ctc_log_likelihood(lp, [1, 2]) > ctc_log_likelihood(lp, [2, 1])
True
Return type:

float

voxy.pronounce.score_readings(log_probs, vocab, readings, *, blank=None)[source]¶

Each reading’s CTC log-likelihood per target symbol (higher is better).

Normalising by length keeps a longer reading (“ɛst”) from losing to a shorter one (“ɛ”) just for having more symbols to pay for. blank defaults to the id of BLANK_SYMBOL in vocab (0 if it has none).

Return type:

dict[str, float]

voxy.pronounce.tokenize_phonemes(reading, vocab)[source]¶

Vocabulary ids of an IPA reading, longest symbol first; spaces are ignored.

A reading may also be given as a sequence of symbols. Raises ValueError on a symbol the recogniser does not know, since it could never be heard.

Verdicts for each (word, readings, expected) at each place ASR found it.
