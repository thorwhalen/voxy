voxy.benchmarks¶

Published benchmarks of the cloning backends, kept as data, rendered as tables and charts.

The data (voxy/data/benchmarks.json) has two parts: models (licence, size, languages, price, watermark per backend id such as "qwen3tts" or "elevenlabs/eleven_v3") and results, one row per published number:

{model, benchmark, metric, value, higher_is_better, source_url, self_reported, retrieved, note?}

docs/benchmarks.md holds the prose; its tables and charts are generated between markers (<!-- voxy-benchmarks:NAME --> … <!-- /voxy-benchmarks -->) by render_docs, from the TABLES and CHARTS specs below. To update: edit the JSON (add rows, keep every source URL), then python -m voxy benchmarks docs/benchmarks.md.

>>> rows = [{"model": "a", "benchmark": "B", "metric": "WER %", "value": 2.0, "self_reported": True,
...          "source_url": "https://x.org/p"}]
>>> print(results_table(rows, [("B", "WER %")], models={"a": {"name": "Model A"}}))
| Model | B (WER %) |
|---|---|
| Model A | [2.0](https://x.org/p) (S) |
